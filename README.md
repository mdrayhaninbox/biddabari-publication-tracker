# বিদ্যাবাড়ি পাবলিকেশন - বুক ম্যানেজমেন্ট ও সেলস ট্র্যাকার
### Biddabari Publication - Book Management, Daily Sales & Inventory Tracking System

একটি আধুনিক, ব্যবহারকারী-বান্ধব এবং রিয়েল-টাইম ওয়েব সফটওয়্যার যা **"biddabari publication all books data.xlsx"** এক্সেল শিটের যাবতীয় হিসাব-নিকাশ, দৈনিক বিক্রয় চ্যানেল ও প্রেস স্টক ট্র্যাক করার জন্য তৈরি করা হয়েছে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **📊 ইন্টারেক্টিভ ড্যাশবোর্ড (Real-time Dashboard)**:
   - হেড অফিস মোট বর্তমান স্টক ও ফরিদ ভাই প্রেস স্টক খতিয়ান
   - মোট বিক্রিত কপি (অনলাইন বনাম অফলাইন শতাংশ সহ)
   - সর্বমোট রাজস্ব (Total Revenue ৳) ও নিট লাভ (Total Net Profit ৳)
   - চ্যানেল অনুযায়ী বিক্রয় (বইবাড়ি, রকমারি, ওয়াফিলাইফ, সুমনা, প্রমিজ, জয়স্টার, নীলক্ষেত ও হেড অফিস কাউন্টার)
   - ৩১ দিনের দৈনিক বিক্রয় গতিধারা বার চার্ট (Daily Sales Velocity Histogram)

2. **📝 দৈনিক বিক্রয় ও চালান এন্ট্রি (Daily Input Form)**:
   - এক্সেল শিটের "Input Form"-এর সম্পূর্ণ আধুনিক বিকল্প
   - যেকোনো বই এবং মাসের যেকোনো দিন (Day 1 - 31) নির্বাচন করে এন্ট্রি দেওয়ার সুবিধা
   - ফরিদ ভাই প্রেস থেকে চালান গ্রহণ, সকল অনলাইন ও অফলাইন চ্যানেলের ডেলিভারি, দৈনিক রিটার্ন এবং মার্কেটিং/উপহার কপির তাৎক্ষণিক হিসাব

3. **📅 ৩১ দিনের সম্পূর্ণ ম্যাট্রিক্স ভিউ (31-Day Complete Matrix)**:
   - মূল এক্সেল শিটের মতো ৩১ দিনের সম্পূর্ণ কলাম ভিউ
   - প্রতিটি চ্যানেলের দিনভিত্তিক হিসাব ও মোট যোগফল
   - যেকোনো ঘরে ক্লিক করে সরাসরি মান এডিট ও তাৎক্ষণিক সেভ সুবিধা

4. **📚 বই তালিকা ও আর্থিক বিশ্লেষণ (Books Management)**:
   - নতুন বই যুক্ত করা, MRP, মেকিং খরচ, বিজ্ঞাপন খরচ ও প্রাক্কলিত লাভ নির্ধারণ
   - লো-স্টক সতর্কতা অ্যালার্ট

5. **📥 এক্সেল এক্সপোর্ট ও ইমপোর্ট (.xlsx Sync)**:
   - এক ক্লিকে মূল এক্সেলের হুবহু ৩৭১-কলাম ফরম্যাটে ফুল ডাটা এক্সপোর্ট
   - এক্সিকিউটিভ রিপোর্ট শিট সহ ডাউনলোড
   - বিদ্যমান এক্সেল শিট আপলোড করে ডাটাবেস আপডেট করার সুবিধা
   - মূল টেমপ্লেট ফাইল ডাউনলোড সুবিধা

6. **🖨️ এক্সিকিউটিভ প্রিন্ট ও PDF রিপোর্ট**:
   - মিটিং ও অডিটের জন্য অফিসিয়াল লেটারহেড ফরম্যাটে প্রিন্ট-রেডি প্রতিবেদন (স্বাক্ষর ব্লক সহ)

7. **💾 লোকালস্টোরেজ অটো-সেভ**:
   - ইন্টারনেট ছাড়াও ব্রাউজারে ডাটা স্বয়ংক্রিয়ভাবে সংরক্ষিত থাকে

## 🛠️ প্রযুক্তি (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide Icons, Hind Siliguri (Bangla Font)
- **Data Engine**: XLSX (SheetJS) for `.xlsx` import/export
- **Deployment**: Vercel & GitHub

## 🚀 লোকাল রান করার নিয়ম (Run Locally)

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# প্রোডাকশন বিল্ড তৈরি করুন
npm run build
```
